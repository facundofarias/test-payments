# Privacy Policy — Test Payments

_Last updated: 7 July 2026_

Test Payments does not collect, store, transmit, or sell any personal or user data.

- The extension operates entirely on your device.
- It contains no analytics, tracking, or telemetry.
- It communicates with no external or remote servers. All test data is bundled inside the extension package.
- The optional "AI Generated" feature uses Chrome's built-in on-device AI (Gemini Nano). Prompts and generated text never leave your device.
- The extension only writes a value you explicitly select into the form field you right-clicked. It does not read, collect, or send the contents of any page you visit.

## Permissions

- **contextMenus** — to show the right-click "Test Payments" menu.
- **Host access** — so the value you select can be inserted into the field on the page you are testing. No page data is read or transmitted.
- **aiLanguageModel** — to run Chrome's on-device AI for the optional identity generators.
